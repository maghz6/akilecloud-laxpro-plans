## 三网优化到底优化的是哪一段

回程。你 ping 一个美国 IP，测到的是去程延迟，数据从机房传回你家里那一段才决定晚高峰卡不卡。国内的 international 出口在晚高峰最堵，机房上游的回国通道是另一个瓶颈，日常的掉速、视频转圈、SSH 输入延迟，多数发生在回程上。

三条线各管一摊：电信的 CN2 GIA 走电信精品承载网，晚高峰最稳，成本也最高；联通的 AS9929（CUII）是联通精品网，业内常跟 CN2 GIA 放同一档讨论；移动的 CMIN2 是移动的精品回程，带宽给得比较大方。选线的第一条原则很朴素：家里装谁家的宽带，就优先买谁家的线。电信用户走 9929 会绕路，移动用户走 9929 延迟也偏高，反过来电信用户走 CMIN2 体验一般。

“三网优化”这个词被用得很泛，至少有两种实现。一种是三网分线，电信回程走 CN2 GIA、联通走 9929、移动走 CMIN2，各走各的；另一种是回程统一走 9929 精品网，三网都从这一条出去。同赛道有完整路由实测的产品可以对照：三网分线的机器，电信回程是 `AS4134 -> AS4809(CN2 GIA)`，联通是 `AS10099 -> AS9929`，移动是 `AS58807(CMIN2)`；而名字里带“9929”的单线产品，联通和移动回程跟三网优化机型本质同路，真正拉开差距的只有电信方向，它是联通 9929 转电信骨干，不是 CN2 GIA。这就是只看线路名容易买错的原因。

AkileCloud 的 LAXPro 节点页面写的是“大陆三网优化、DNS 解锁流媒体、美国原生 IP”，没有写明是三网分线还是统一走 9929。这一点值得在下单前用工单问清楚，或者开通后自己 traceroute 三个方向验证。它不影响你判断价格，但影响你对电信方向体验的预期。

同赛道看，VMISS 的 TRI 三网优化和它的 9929、CMIN2 单线是同价（5 加元/月起），价差不在“优化”两个字上，在带宽和流量配置。Akile 这边 LAXPro ¥43.74 起、LAX4837 ¥54.99 起，差距主要来自端口和流量，不是线路等级。

**300G 一个月够不够？**
一个人日常代理加流媒体，一天 10G 左右，300G 刚好。挂下载、跑同步、多人共用，通常两周内就见底。不确定就先按 Standard 的 1000G 算。

**IP 被墙能退款吗？**
退款按上面那套天数比例走，跟被墙没有单独的豁免条款。三天内发现问题退 80%，超过十天不退。换 IP 是另一条路，35 元一次。

**晚高峰会不会掉速？**
三网优化线路的设计目的就是应对晚高峰，丢包和延迟波动会比普通国际线路小。实际表现取决于机房带宽和超售程度，Akile 页面没有给晚高峰实测数据。开通后当天用 Looking Glass 或本地 traceroute 测三个方向，比看任何测评都准。
